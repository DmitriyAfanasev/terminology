# Сервис терминологии

Независимый сервис справочников (коды данных и их значения) для обмена электронными
документами: справочники → версии → элементы. REST API + админ-панель на русском языке.

* **Django 6**, SQLite, Python ≥ 3.12 (этого требует сам Django 6)
* **Асинхронный** (ASGI): доступ к БД — через async ORM (`aget`, `afirst`, `aexists`, `async for`)
* REST API — **[django-modern-rest](https://github.com/wemake-services/django-modern-rest)** (async-контроллеры,
  pydantic), OpenAPI/Swagger
* Менеджер пакетов — **uv**, линтер и форматтер — **ruff**

## API

### `GET /refbooks/[?date=ГГГГ-ММ-ДД]` — список справочников

Без `date` — все справочники. С `date` — только те, у которых есть версия с датой начала
действия ≤ указанной.

```json
{
  "refbooks": [
    {
      "id": "1",
      "code": "MS1",
      "name": "Специальности медицинских работников"
    }
  ]
}
```

### `GET /refbooks/<id>/elements[?version=<версия>]` — элементы справочника

Без `version` — элементы **текущей** версии (самая поздняя дата начала, но не позже сегодня).

```json
{
  "elements": [
    {
      "code": "J00",
      "value": "Острый назофарингит (насморк)"
    }
  ]
}
```

### `GET /refbooks/<id>/check_element?code=<код>&value=<значение>[&version=<версия>]`

Проверяет, что элемент с таким кодом **и** значением есть в версии (по умолчанию — в текущей).

```json
{
  "valid": true
}
```

### Ошибки

| Код | Когда                                                                     |
|-----|---------------------------------------------------------------------------|
| 400 | неверная дата, не переданы `code`/`value`                                 |
| 404 | справочник не найден; версия не найдена; у справочника нет текущей версии |

Тело ошибки — стандартная модель django-modern-rest: `{"detail": [{"msg": ..., "type": ...}]}`.

```bash
curl "http://127.0.0.1:8000/refbooks/?date=2022-10-01"
curl "http://127.0.0.1:8000/refbooks/1/elements?version=1.0"
curl "http://127.0.0.1:8000/refbooks/1/check_element?code=3&value=Хирург&version=1.0"
```

## Админ-панель

* **Справочники**: список — ID, код, наименование, текущая версия, дата её начала; при
  редактировании — список версий (редактируемый, со ссылкой на страницу версии).
* **Версии справочников**: список — код и наименование справочника, версия, дата начала;
  при редактировании — справочник, версия, календарь и **элементы версии** (inline).
* **Элементы справочников**: версия выбирается из списка «справочник-версия» (`MS1-1.0`).

## Ограничения целостности (на уровне БД)

`Refbook.code` уникален · уникальна пара (справочник, версия) · уникальна пара
(справочник, дата начала) · уникальна пара (версия, код элемента).
